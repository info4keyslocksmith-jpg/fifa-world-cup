Repoint the MV55G to this server (SMS)

  • APN,your.apn# or APN,your.apn,user,password#
  • SERVER,0,<public-ip>,<port>#  (mode 0 = IP)  ·  SERVER,1,<dns-name>,<port>#  (mode 1 = domain)
  • TIMER,30# report interval (s) · SPEED,120# overspeed · GMT,E,0# time zone
  • ACCALM,1# PWRALM,1# SENALM,1# ignition / unplug / vibration alerts
  • VERSION# returns firmware + the device ID the server will see · STATUS# · PARAM# · RESET#

MiCODUS replies "SET APN OK" even for a wrong APN, so a positive SMS reply does not prove the device is online. Full list with sources: docs/SMS-COMMANDS.md. Change the default password (123456) first.

What a healthy MV55G session looks like (JT808)

  1. 0x0100 register (manufacturer/model) → server 0x8100 success + auth code
  2. 0x0102 auth → server 0x8001
  3. 0x0002 heartbeat every few minutes → 0x8001
  4. 0x0200 location on each interval, OBD items inside (RPM 0x81, voltage 0x82, …) → 0x8001
  5. alarm bits in the location report (bit 8 unplug, bit 1 overspeed, bit 28 moved) and 0x57 harsh driving
  6. 0x0704 batch after a dead zone

The device identifies itself by the 11/12-digit MiCODUS ID (0 + sticker ID), not by IMEI. GT06 devices (MV7xx) identify by IMEI and are decoded too.

Online commands (Commands tab)

  • STATUS# · PARAM# · VERSION# · WHERE# · MILEAGE# — sent as 0x8300 text
  • TIMER,30# · SPEED,120# · ACCALM,1# — settings
  • !query 0x8201 position request → 0x0201 reply
  • !params 0x8104 parameter dump → 0x0104 reply
  • !reset 0x8105 reboot · !text,4,hello 0x8300 with another flag byte

The device answers each of our messages with 0x0001 (accepted / unsupported) and then, for text commands, a text reply. Never use relay / engine-cut commands.
