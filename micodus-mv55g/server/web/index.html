Repoint the tracker to this server (SMS)

  • APN,your.apn.here#  (SIM operator APN; add ,user,pass if needed)
  • SERVER,1,<public-ip-or-dns>,<tcp-port>,0#  (mode 1 = IP, 0 = domain; last 0 = TCP)
  • RESET#  to reconnect
  • Check PARAM# / STATUS# / VERSION# by SMS to confirm

The exact MiCODUS command spelling is in docs/SMS-COMMANDS.md. Change the default password (123456) before anything else.

What a healthy session looks like

  1. 0x01 login with the IMEI → server ACK
  2. 0x8A time request → server sends UTC time (optional)
  3. 0x13 / 0x23 heartbeat every few minutes → ACK
  4. 0x22 / 0x12 / 0xA0 location on each interval → ACK
  5. 0x16 / 0x26 alarms (power cut, vibration, ...) → ACK
  6. 0x94 info (external voltage, ICCID) and OBD-related frames

Online commands to try from the Commands tab

Command strings sent inside a 0x80 frame. Family-standard; MiCODUS firmware may accept a subset.

  • STATUS# battery / GSM / GPS state
  • PARAM# current parameters
  • VERSION# firmware version
  • WHERE# text position
  • GPSON# / GPSOFF#
  • TIMER,10,300# report interval (moving, stopped)
  • RESET# reboot
